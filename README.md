# MarketHub

**MarketHub** — frontend-панель управления магазином и маркетплейсом.

Проект показывает, как может выглядеть рабочее пространство менеджера: обзор продаж, каталог товаров, заказы, клиенты, операционные задачи и уведомления. Интерфейс адаптирован под desktop и mobile и поддерживает светлую и тёмную темы.

> Это frontend-проект для портфолио. Данные работают через локальный mock API layer, поэтому приложение запускается без отдельного backend-сервера.

## Возможности

### 📊 Обзор
- ключевые показатели магазина: оборот, заказы, клиенты и товары;
- график динамики продаж;
- переключение периода: 7 дней / 30 дней / 3 месяца;
- распределение продаж по категориям;
- список последних заказов.

### 📦 Товары
- каталог товаров;
- поиск и фильтрация;
- сортировка и пагинация;
- создание, редактирование и удаление товаров;
- просмотр карточки товара;
- валидация форм.

### 🛒 Заказы
- поиск по заказу, клиенту и контактным данным;
- фильтрация по статусу и каналу продаж;
- расчёт оборота, количества заказов и среднего чека по текущей выборке;
- просмотр деталей заказа;
- экспорт выбранных данных в CSV.

### 👥 Клиенты
- таблица клиентов;
- поиск и фильтрация;
- создание, редактирование и удаление записей;
- синхронизация параметров таблицы с URL.

### ✅ Задачи и уведомления
- Kanban-доска для операционных задач;
- создание и перемещение задач;
- центр уведомлений.

## Архитектура

Проект организован по feature-based подходу:

```text
src/
├── components/        # общие UI-компоненты и layout
├── config/             # конфигурация приложения
├── constants/          # mock-данные
├── features/
│   ├── products/       # товары + API layer + компоненты
│   ├── users/          # клиенты + API layer + компоненты
│   ├── orders/         # заказы
│   ├── overview/       # аналитика и обзор
│   ├── kanban/         # задачи
│   └── notifications/  # уведомления
├── routes/             # маршруты TanStack Router
└── styles/             # глобальные стили и темы
```

В слоях `features/*/api` отделён доступ к данным от UI. Сейчас там используется mock-реализация, но её можно заменить на REST/GraphQL API без переписывания компонентов страниц.

## Запуск

Требуется **Node.js 18+**.

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

Сборка production-версии:

```bash
npm run build
```

Проверка качества кода:

```bash
npm run lint
npm run format:check
```

## Принципы интерфейса

Дизайн построен вокруг задач commerce-admin интерфейсов:

- высокая информационная плотность без перегруженности;
- понятная иерархия данных;
- таблицы и фильтры как основные рабочие инструменты;
- семантические статусы и уведомления;
- адаптивная вёрстка;
- светлая и тёмная темы.

Визуальное направление вдохновлено подходами современных commerce-admin систем, в том числе Shopify Polaris. Брендинг и проприетарные ассеты Shopify в проекте не используются.

## Статус проекта

Проект предназначен для демонстрации frontend-разработки и архитектурных решений.

Backend намеренно не включён: mock API layer позволяет демонстрировать работу интерфейса, состояний, фильтрации, CRUD-сценариев и аналитики без внешней инфраструктуры.
